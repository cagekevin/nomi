# Nomi 本地文件导入链路（100% 对照源码）

> 本文档只描述 Nomi 这边的本地文件（图片/视频）从「渲染层拖入」到「落盘为 nomi-local 资产」的完整传递链路。
> 不涉及任何 lovart 代码。所有结论均逐行对应下列源码文件，引用格式 `行号:文件`。

## 一、链路总览

```
渲染层拖拽/粘贴
  → assetImportAdapter.importLocalMediaFilesToGenerationCanvas()      [src]
  → assetUploadApi.importWorkbenchLocalAssetFile()                     [src]
  → desktop.assets.importFile()  (preload 桥，ipcRenderer.invoke)      [electron/preload.ts]
  → IPC 通道 nomi:assets:import-file
  → assetsIpc.registerAssetsIpc() → importLocalFile()                  [electron/assets/assetsIpc.ts]
  → localFileImport.importLocalFile()                                  [electron/assets/localFileImport.ts]
      └─ (视频) ensurePlayableVideoBytes() 归一化
  → runtime.writeAsset() (re-export from projectAssetStore)            [electron/assets/projectAssetStore.ts]
  → 返回资产 DTO，其中 data.url 即 nomi-local:// 持久化 URL
  → 渲染层 hostedAssetUrl(dto) 取 url 写入画布节点
```

## 二、逐段说明（含真实代码）

### 1. 渲染层入口与过滤
文件：`src/workbench/generationCanvas/adapters/assetImportAdapter.ts`

- `importLocalMediaFilesToGenerationCanvas(inputFiles, options)` 是统一入口（`:277`）。
- 先用 `filterImportableMediaFiles()`（`:159`）过滤：
  - 只接受 `image` / `video`（`importKindForFile`，`:154`，内部用 `dropKindFromFile` 判断）。
  - 去重：`fileSignature = 文件名|type|size`（`:126`）。
  - 大小上限：图片 `30MB`（`GENERATION_CANVAS_IMAGE_IMPORT_MAX_BYTES`，`:13`）、视频 `600MB`（`GENERATION_CANVAS_VIDEO_IMPORT_MAX_BYTES`，`:15`）。
  - 单次拖入上限 `8` 个（`MAX_IMPORT_FILES`，`:290`），超出截断，计数 `skippedOverLimitCount`。
- 每个文件：先建画布 asset 节点（`status: 'queued'`），再并发调用上传（`:318`–`:339`、`:342`）。

### 2. 上传 API（File → ArrayBuffer → IPC payload）
文件：`src/workbench/api/assetUploadApi.ts`

- `importWorkbenchLocalAssetFile(file, name, meta)`（`:68`）：
  - `const arrayBuffer = await file.arrayBuffer()` —— 文件以 **ArrayBuffer** 形式传入。
  - 调用 `desktop.assets.importFile({ projectId, fileName, contentType, bytes: arrayBuffer, kind: 'upload' })`（`:75`–`:81`）。
  - `projectId` 来自 `resolveProjectId(meta)`，缺省取当前激活项目 `getDesktopActiveProjectId()`（`:37`）。
  - **注意**：此处硬编码 `kind: 'upload'`，未用 `meta.kind`。
- `hostedAssetUrl(asset)`（`:16`）：取 `asset.data.url` 作为可持久化 URL（空则回空串）。
- `recoverImportedWorkbenchLocalAssetFile()`（`:99`）：**当前恒返回 `null`**，即无断点续传/恢复能力。

### 3. Preload 桥（渲染→主进程）
文件：`electron/preload.ts`

- `importFile: (payload) => ipcRenderer.invoke(IpcChannels.assetsImportFile, payload)`（`:165`）。
- 通道名常量 `assetsImportFile: "nomi:assets:import-file"`（`electron/shared/ipcChannels.ts:104`）。

### 4. 主进程 IPC 接收
文件：`electron/assets/assetsIpc.ts`

- `ipcMain.handle(IpcChannels.assetsImportFile, …)` → 动态 import `localFileImport.importLocalFile(payload)`（`:16`–`:19`）。

### 5. 字节还原 + 视频归一化 + 落盘
文件：`electron/assets/localFileImport.ts`

- `importLocalFile(payload)`（`:23`）：
  - `projectId = String(raw.projectId)`（必需，否则抛错，`:25`）。
  - `bytes = bytesFromPayload(raw.bytes)`：支持 `ArrayBuffer` / `ArrayBuffer.isView` / `Array` → `Buffer`（`:16`、`:27`）。
  - `contentType`、`fileName` 取 payload 字段，缺省 `application/octet-stream` / `asset-<ts>.ext`（`:28`–`:30`）。
  - **视频分支**（`:32`）：`contentType.startsWith("video/")` 时先调 `ensurePlayableVideoBytes(bytes, fileName, contentType)` 做可播放归一化（HEVC/AVI 等 Chromium 解不了的转 H.264+AAC MP4；失败回退原字节不挡导入）。归一化实现见 `videoImportNormalize.ts`。
  - 最终 `writeAsset(projectId, normalized?.bytes ?? bytes, normalized?.fileName ?? fileName, normalized?.contentType ?? contentType, { kind: raw.kind || "upload", originalName, ...playbackNormalizedFrom })`（`:35`–`:45`）。

### 6. 资产落盘与 DTO 返回
文件：`electron/assets/projectAssetStore.ts`

- `writeAsset(projectId, bytes, fileName, contentType, rawMeta)`（`:83`）：
  - `meta = sanitizeAssetMetaForKind(rawMeta)`。
  - 落盘路径：`assets/<bucket>/<YYYY-MM-DD>/<fileName>`，`bucket` 由 `assetBucketFromMeta(meta)` 决定（`:92`）。
    - `upload` / `imported` / `local` / 浏览器捕捞类 → `imported` 桶（`:58`–`:64`）。本地上传走此桶。
  - `fs.writeFileSync(absolutePath, bytes)`（`:93`）+ 写 `.meta` 侧车文件（`:94`）。
  - `broadcastAssetsUpdated(projectId)` 广播资产更新事件（`:95`）。
  - 返回 DTO（`:98`–`:113`）：
    ```
    {
      id: "asset-<uuid>",
      name, userId: "local", projectId,
      createdAt, updatedAt,
      data: { ...meta, url, relativePath, absolutePath, contentType, size }
    }
    ```
  - `url = localAssetUrl(projectId, relativePath)` 即 `nomi-local://` 持久化地址。

### 7. 渲染层回填节点
文件：`src/workbench/generationCanvas/adapters/assetImportAdapter.ts`

- `uploadAndApplyAssetToNode()`（`:202`）：
  - 成功：`hosted = await deps.uploadFile(...)`，取 `hostedUrl = hostedAssetUrl(hosted)`。
  - 视频额外 `probeVideoDuration(hostedUrl)` 探测时长（`:238`）。
  - 把 `result = { id, type: kind, url: hostedUrl, assetId: hosted.id, raw: { asset: hosted }, createdAt }` 写入节点 `result`/`history`，`status: 'success'`，`meta.source: 'asset-upload'`、`serverAssetId`（`:239`–`:261`）。
  - 失败且无 data-url 兜底：节点 `status: 'error'`，留 File 供「重试导入」（`:216`–`:236`）；图片 ≤`512KB` 可退化成 data-url 落盘（`:218`）。

## 四、调用方（谁触发导入）

- 拖拽：经 `assetImportAdapter.importLocalMediaFilesToGenerationCanvas`。
- 浏览器素材弹层：`src/ui/browser/popover/NomiBrowserAssetPopover.tsx`（引用 `assetImportAdapter`）。
- 剪贴板粘贴图片：`src/workbench/generationCanvas/adapters/clipboardImagePaste.ts`。
- 白板绘图案：`src/workbench/generationCanvas/nodes/whiteboard/WhiteboardDrawingTool.tsx`。

## 五、失败语义

- 上传/落盘失败：节点进入 `error` 态，文案「本地素材复制失败，可点节点上的『重试导入』」；`≤512KB` 图片降级为 data-url 落盘（不依赖主进程写盘）。
- 视频归一化失败：不阻断导入，原字节照常落盘（坏视频在播放面由 `ensurePlayableAsset` 懒自愈转码）。
