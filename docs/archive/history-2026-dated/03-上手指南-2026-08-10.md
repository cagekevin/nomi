# Nomi 上手指南（普通用户篇）

> 适用对象：你拿到了 Nomi 桌面端，想从「第一次打开」到「导出第一支视频」跑通，**不需要会写代码、不需要装 Node / pnpm**。
> 如果你是想从源码 build 起来的开发者，去看 [`01-用户指南-2026-08-10.md`](01-用户指南-2026-08-10.md)；如果你想用 Claude Code / MCP 远程驱动 Nomi，去看 [`guide/capability-core-cli-mcp.md`](guide/capability-core-cli-mcp.md)。
> 本指南是「用户视角的一条最短路径」，每一步都标了你会看到什么、要做什么。

---

## 一句话逻辑

Nomi 帮你把「一句话的创意」变成「一支能导出的视频」，全程本地优先、自带模型不托管：

**写意图 → 接模型 → 生成图/视频 → 排时间轴 → 导出 MP4**

你唯一要准备的「原料」是：至少一个能用的 **AI 模型**（图模型出图、视频模型出片、文本模型写脚本）。没有模型 Nomi 也能打开，但生成不了东西——所以第一步永远是「接模型」，不是「找素材」。

> 诚实边界：Nomi 是 **Bring Your Own Models** 工具。它本身不送你额度，你要去供应商那里开个 Key 填进来。项目的提示词、素材、Key 全存在你本机，不上传任何服务器、无账号、无遥测。

---

## 第 0 步：装好并打开

| 系统 | 下载 | 注意 |
|---|---|---|
| macOS（Apple Silicon） | `Nomi-mac-arm64.dmg` | 拖进 Applications 后，终端跑一次 `xattr -cr /Applications/Nomi.app` 再打开 |
| macOS（Intel） | `Nomi-mac-intel.dmg` | 同上 |
| Windows 10 / 11 | `Nomi-windows-setup.exe` | SmartScreen 弹窗里选 **更多信息 → 仍要运行** |

下载入口见 [README](README.md)。装完第一次打开即可，不用配置任何东西。

---

## 第 1 步：接入你的第一个模型（最关键）

> 这是新手最容易卡住的一步，所以放最前。没有模型 = 后面全灰。

**路径**：顶部工具栏 → **模型接入** → 添加供应商，按提示填：

1. 填供应商名称 + **API Base URL**
2. 填你的 **API Key**（只存本机 `userData/catalog.json`，不上传）
3. 选模型类型（文本 / 图片 / 视频）
4. 填请求字段（提示词、宽高比、时长、模型名等）
5. 点 **「测试」** 验证连通
6. 保存 → 画布节点里就能选这个模型了

### 不知道接哪个？给个最小套餐

| 用途 | 推荐供应商 | 获取 Key |
|---|---|---|
| 写脚本 / 拆镜头（文本） | DeepSeek `deepseek-chat` | [platform.deepseek.com](https://platform.deepseek.com) |
| 出概念图（图片） | 即梦 Jimeng（国内便宜） | [volcengine.com/product/jimeng](https://www.volcengine.com/product/jimeng) |
| 出视频片段（视频） | 可灵 Kling / 火山方舟 Seedance | [klingai.com](https://klingai.com) · [console.volcengine.com/ark](https://console.volcengine.com/ark) |

> 想接 Claude 系列？模型接入里把**供应商类型**选 `Anthropic`，Base URL 默认 `https://api.anthropic.com`，Key 填 `sk-ant-...` 即可，和 OpenAI 兼容供应商共用同一套工具调用，不用写配置。
> OpenAI 兼容接口（GPT 系列、通义千问、本地 Ollama 等）都直接支持，Base URL 填对应地址就行。
> 嫌手填麻烦？在生成区 AI 面板把供应商 API 文档 URL 发给内置 Agent：「帮我接入 xxx，文档在 https://docs.xxx.com/api」，它会出草稿，你确认保存即可。

## 第 2 步：写你的意图（创作区）

打开 Nomi 后，默认进入**项目库**。新建一个项目，进到**创作区**：

- 左侧面板选项目和章节
- 直接在编辑器里写剧本 / 章节 / 镜头描述
- 内容**自动保存**到本地 `文档/Nomi Projects`，关了也不丢

**懒人捷径**：不自己写，让文本模型帮你拆。创作区工具栏右上角有 **「拆镜头」** 按钮，一键把当前文档拆成故事板；或在生成区 AI 面板说「把这段故事拆成 6 个镜头，每个镜头一张图」。

---

## 第 3 步：生成图 / 视频（生成区·画布）

创作区写完，进入**生成区（画布）**——这里是把文字变画面的地方。

### 加节点
点工具栏 **`+`** → 选节点类型（图片 / 视频 / 文本 / 角色 / 场景…）。

### 出一张图
1. 选中图片节点
2. 下方输入框写提示词（如「晨光中的咖啡杯特写，蒸汽升腾，暖色调」）
3. 点 **「生成 →」**，选第 1 步接好的图模型

### 出一段视频
视频节点要先连一张图当**首帧**：
1. 点图片节点右侧的连接点
2. 拖线到视频节点左侧
3. 填提示词 → 点「生成 →」，选视频模型

> 提示词写得越具体（主体 + 光线 + 色调 + 镜头），出图越贴近你想的。角色 / 场景节点可以「锁一次、后续继承」，避免第 4 镜和第 9 镜变成两个人（这是 Nomi 的核心卖点之一）。

### 画布快捷键
| 操作 | 快捷键 |
|---|---|
| 复制节点 | Cmd/Ctrl + D |
| 删除节点 | Delete |
| 适应视图 | 工具栏 ⌖ 按钮 |
| 平移画布 | 拖拽空白区域 |

### 让 Agent 替你干活（可选）
生成区右侧有 **AI 面板**，用自然语言控制画布，比如：
- 「读当前画布，把所有图片节点都连一条线到视频节点」
- 「帮我把这段段落改写得更口语化」

Agent 的工具调用会弹**确认卡**，你点头才执行，画布实时显示节点出现的过程。

---

## 第 4 步：排成视频（时间轴）

素材生成好了，进**时间轴**把它们排成成片：

- **加素材**：从生成区把节点拖到时间轴轨道上
- **移动 / 裁剪 / 分割**：拖拽片段；悬停边缘拖 handle 裁剪；选中按 `S` 分割
- **复制 / 删除**：`Cmd/Ctrl + D` / `Delete`
- **微移**：`Shift + <` / `>`
- **缩放**：`Ctrl/Cmd + 滚轮` 或工具栏 +/−
- **播放预览**：点播放按钮或按空格

---

## 第 5 步：导出 MP4

点预览区右上角 **「导出 MP4」**：

- 格式：MP4（H.264），1080p / 30fps
- 音频：随片导出视频自带音轨，多段自动混音
- **所见即所得**：导出画面与预览完全一致（不留裁切，letterbox WYSIWYG）
- 保存位置：项目 `exports/` 文件夹，完成自动打开所在文件夹

> 极少数情况下个别素材解析/编码失败，会自动回退为静音 WebM 保证导出不中断。

## 最小上手清单（抄这条就行）

```text
1. 下载安装 Nomi，第一次打开
2. 模型接入 → 加一个图模型（如即梦）+ 一个文本模型（如 DeepSeek）
3. 新建项目 → 创作区写一句话 / 点「拆镜头」
4. 生成区加图片节点 → 写提示词 → 生成
5. 拖到时间轴 → 排顺序 → 导出 MP4
```

做到第 5 步，你就有了第一支能发的片。剩下的（多镜头叙事、角色锁定、视频生成、ComfyUI 本地工作流、MCP 远程驱动）都是在这条主干上长出来的枝。

## 安全须知（一眼看完）

- 你的项目、素材、提示词、API Key **全在本机**，不上传任何服务器、无账号、无遥测。
- 「本地优先」不等于「所有推理离线」：调外部模型 API 时，完成任务所需的输入仍会发给你的供应商。
- 不要把你本机的用户配置目录提交到 Git。
