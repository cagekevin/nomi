# 带图聊天链路排查

定位「Nomi 带图聊天」异常的断点。源码已埋点 A–F（DEBUG 级、仅带附件才打，不删）。

## 日志在哪
- Windows：`%USERPROFILE%\AppData\Roaming\nomi\logs\nomi.log`
- macOS：`~/Library/Logs/nomi/nomi.log`
- 记下排障时间点，看 `ts` 附近。

## 开 DEBUG
启动前 `$env:NOMI_LOG_LEVEL="DEBUG"`（PowerShell），否则埋点 A–F 不落盘。

## 埋点链路（搜 `[nomi:agent`，同 traceId=同一次请求）
| 断点 | 位置 | 含义 |
|---|---|---|
| A | 渲染层 desktopAgentsChatStream 发起点 | 附件是否随 payload 发出 |
| B | agentChatV2Ipc IPC 入口 | attachments 是否到主进程 |
| C | agentChatV2 runAgentChatV2 | 附件进主进程链路 |
| D | 同 | 选中模型 + supportsImageInput |
| E | resolveBytes 闭包 | 每张图本地读字节结果 |
| F | buildAgentUserContent 后 | 产出几个 image part |

## 判断
- D 里 `supportsImageInput:false` → 图被本地门控丢。
- E 是 `NULL(读不到字节)` → readNomiLocalAsset 读不出。
- F 是 `imageParts:0` → 图片 part 被丢。
- F 有 imageParts≥1 → 图已序列化成 data:base64 发出，断点在网关→Lovart 上游（网络）。

## 已实证（2026-08-10）
> 状态：此问题**已定位并修复**，以下结论是历史实证，非待查项。

图确实从 Nomi 发出了，失败点是**网络**：`上传连接失败(直连及代理均不可达)`、`连接 Lovart 失败`、`模型首字块超时`。
代理 `127.0.0.1:7897` 重传也失败 → 代理不稳定或 Lovart 域名没走对代理。偶发 `Server disconnected` 是瞬断，别当根因。
确认 VPN/代理开着、能访问 `lgw.lovart.ai` 再重跑。
