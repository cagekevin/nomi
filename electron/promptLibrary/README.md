# electron/promptLibrary

提示词库（内置包 + 用户包）存储与解析。

- `builtinPacks.ts` / `builtinExpressionPack.json` / `promptLibrarySeed.json`：内置包与种子数据。
- `userPromptStore.ts` / `promptLibraryStore.ts`：用户提示词与库存储。
- `promptParsers.ts` / `promptSources.ts` / `promptLibraryTypes.ts`：解析、来源、类型。
- `promptLibraryIpc.ts`：IPC。
