# src/media

前端侧媒体（视频/音频）播放、时长探测与诊断。

- `nomiLocalAssetUrl.ts`：本地素材 URL 解析。
- `videoDurationProbe.ts` / `audioDurationProbe.ts`：媒体时长探测。
- `useFilmstrip.ts`：胶片条（关键帧条）hook。
- `useVideoPlaybackHeal.ts` / `videoPlaybackDiagnostics.ts` / `VideoPlaybackStatusOverlay.tsx`：播放自愈与诊断。
- `videoPlaybackUrl.ts`：播放 URL 处理。
